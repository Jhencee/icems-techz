ICEMS APK Downloads Folder
===========================
Place your Flutter APK file here and name it:

    ICEMS.apk

Then it will be available at:
    https://your-domain.com/downloads/ICEMS.apk

To generate a release APK from Flutter, run:
    flutter build apk --release
Then copy:
    build/app/outputs/flutter-apk/app-release.apk
To this folder and rename it to ICEMS.apk
